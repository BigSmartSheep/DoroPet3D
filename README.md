# Doro 桌面寵物

## 操作
- 用右鍵按住 Doro 進行拖曳，拖曳期間可用滾輪調整縮放大小。
- 首次運行後，應用程式會在目前帳戶登入 Windows 時自動啟動。

---
# Doro Desktop Pet

## Operation

- Right-click and hold Doro to drag it. Use the scroll wheel to adjust the size while dragging.

- The application will automatically launch when the current account logs into Windows after the first execution.
